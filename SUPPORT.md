# Support

## Questions and usage help

Read the repository README and documentation first. If the answer is not covered, open an issue and apply the `question` label when available.

Include:

- What you are trying to accomplish
- Relevant versions and environment details
- The smallest useful configuration or example
- Exact errors or unexpected behavior
- What you already tried

## Bugs

Use the bug report form. Remove credentials, private paths, personal data, and proprietary source before posting logs or screenshots.

## Feature requests

Use the feature request form and describe the user problem before proposing an implementation.

## Security

Do not request security support through a public issue. Follow `SECURITY.md`.

These repositories are maintained as time permits. Community support and well-scoped pull requests are welcome, but response times are not guaranteed.
