# Community health files

These are the default community health files for Raymond Ware's public repositories.

GitHub uses them when a repository does not provide its own version. A repository-specific file always takes precedence.

Included defaults:

- Code of conduct
- Contributing guide
- Security policy
- Support guide
- Bug and feature-request forms
- Pull-request template

Individual projects may add more specific instructions, build commands, or support policies in their own repositories.
